# 升级到 7.0

7.0 保留现有 CLI/MCP 参数、五个预设、公开结果结构和下载目录约定。
需要适配的是访问停止行为、PDF 正文呈现及旧提取缓存。

| 场景 | 7.0 行为 | 调用方需要处理 |
| --- | --- | --- |
| 同篇正文明确付费墙或官方全文 API 拒绝 entitlement | 停止后续候选、重试、PDF 恢复及资产请求；允许降级时使用已收到摘要/元数据 | 根据 acceptance 和访问诊断判断结果，不再期待确认付费墙后穷尽其他路线 |
| PDF 正文 | 保留现有 `pymupdf4llm` 输出，不做项目层内容修复 | 更新依赖旧标题、空白、引用或表格清洗结果的断言；本地资产路径仍可按落盘位置改写 |
| 6.2.4 的 HTML/XML/PDF 提取缓存 | 修订号 5 不再命中当前修订号 6 | 首次请求可能重新联网获取；已保存文件保留，不需要清空整个下载目录 |
| PLOS 部分资产下载 | 精确对象绑定本地文件，其余保留官方远程 URL | 需要完整离线正文时继续使用既有本地资产验收约束 |

安装更新沿用 [部署指南](deployment.md#8-更新方式)。源码开发环境执行
`uv sync --frozen --extra dev --extra full`；在线安装使用原 Python 环境重新安装，
离线安装使用对应平台/ABI 的 7.0 安装包覆盖升级，然后重启 MCP host。
通过 `paper-fetch --version` 确认正在运行 7.0.0。

历史来源、采集事件和旧输出不因升级而重写。PDF 转换质量继续属于上游边界，
详见 [PDF 转换约束](extraction-rules.md#rule-pdf-conversion-boundary)。
从 6.0 之前升级时，还需查看 [6.0 迁移说明](migration-v6.md)。
