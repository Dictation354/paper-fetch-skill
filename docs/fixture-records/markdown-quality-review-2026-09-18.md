## 方法和边界

优先使用 2026-09-18 来源补齐 JSON 中的 `source`，其余复用上一轮已核验源。每次回放前后核对原始 SHA-256；用现有 provider builder 提取，`include_refs=all`、`max_tokens=full_text`、`asset_profile=all` 导出，不修改导出正文。进程禁止网络，4 个 worker 并行处理。比较正文顺序、图注和图片身份、MathML/TeX、表格单元格与书目数量；额外检查旧测试遗漏的 SVG object/内联图形及公式懒加载地址。

本轮没有逐张截图审查位图，也没有访问远程图链验证 HTTP 状态。17 个已有本地图片按原始相对路径复制进审阅目录，字节/hash 不变，仅解决导出位置；不能据此声称所有远程图片已离线归档。PDF 不进行转换质量评分、清洗或修复。历史 HTTP403 和访问拒绝仍保持原状态。
